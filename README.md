# Forensic_Art
PAUSED. This repository is a curated portfolio of crime scene sketches. The goal is to combine art and science to create educational, visually clear, and accurate representations.
Objectives:

- Visualize forensic concepts for educational and portfolio purposes.

- Blend artistic skill with forensic understanding.

- Document and track the ongoing development of forensic-art illustrations.

### Methods: All illustrations are hand-drawn, labelled directly on paper. and compiled into files for accessibility and clarity. 
This portfolio is meant only for learning and exploration.
Every crime related illustration has fictional cases; any relation with any real event or person is completely a coincidence.
